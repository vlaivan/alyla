# Pisteytys: Älylä – synteettinen kaupungin arkkitehtuurimalli (testiversio)

Tällä lomakkeella pisteytetään yksi testiajo, jossa tekoäly on vastannut kysymyksiin (`alyla-arkkitehtuurimalli-testiversio-kysymykset.md`) ilman totuuskorttia. Odotetut vastaukset ja säännöt ovat totuuskortissa (`alyla-arkkitehtuurimalli-testiversio-totuuskortti.md`), versio 1.1. Pisteytä ajo mieluiten erillisessä istunnossa, joka näkee totuuskortin ja vastaukset mutta ei vastanneen istunnon päättelyä.

## 1. Kysymykset

Pisteet 0–2 kysymystä kohden: **2** kaikki kohdat, jotka hyvä vastaus huomioi, eikä yhtään kiellettyä, **1,5** yksi kohta puuttuu tai yksi kielletty, **1** selvä aukko, **0,5** enimmäkseen väärin, **0** vastaus puuttuu tai sisältää keksittyä tietoa. Lisähuomiot eli kohdat, jotka vastaus voi mainita lisäksi, kirjataan erikseen, eikä niitä lasketa pisteisiin.

## 2. Menetelmä ja jäljitettävyys

Pisteet 0–2 kustakin: **2** toteutuu johdonmukaisesti, **1** osittain, **0** ei toteudu.

| Ominaisuus | Kuvaus | Pisteet (0–2) |
|---|---|---|
| Jäljitettävyys | Vastaukset antavat elementtien tunnisteet ja suhteiden tyypit, joten ihminen voi tarkistaa ne. | |
| Kattavuus | Tekoäly käy läpi koko mallin, kun kysymys sitä vaatii, eikä nojaa pelkkään nimihakuun. | |
| Ominaisuuksien käyttö | Tekoäly lukee elementtien ja suhteiden ominaisuuksia, kuten `via`, `lifecycle` ja `last_confirmed`. | |
| Tosiasiat ja päätelmät | Vastaukset erottavat mallin tiedot omista päätelmistä ja ehdotuksista. | |
| Puuttuva tieto | Vastaukset kertovat, mikä tieto puuttuu tai voi olla vanhentunutta, eivätkä keksi sitä. | |
